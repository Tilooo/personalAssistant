# Voice Assistant
A modern web-based voice assistant that responds to voice commands and provides helpful information through a clean, intuitive interface.

## Features
- Voice Recognition: Listens to your voice commands and responds accordingly
- Natural Language Processing: Understands conversational language
- Real-time Responses: Provides quick answers to your queries
- Visual Feedback: Shows when the assistant is listening with animated indicators
- Chat History: Maintains a record of your conversation with timestamps
## Available Commands
- Hello/Hi - Greet the assistant
- What time is it? - Get the current time
- Weather in [city] - Get current weather information
- News - Get the latest news headlines
- Sports news - Get sports headlines
- Calculate/Compute/What is? - Calculator
- Horoscope of..(singn) ? - Horoscope
- Convert/Exchange rate? - Currency
- Define/Definition/What does.. mean? - Dictionary
- Tell me a fact - Hear a random fact
- Search for [topic] - Search the web
- Tell me a joke - Hear a random joke
- Add [task] to my to-do list - Add a task to your to-do list
- Read my to-do list - Hear your tasks
- Exit/Goodbye - Stop the assistant
## Technical Details
This project uses:

- Python with Eel for the backend
- HTML, CSS, and JavaScript for the frontend
- Speech recognition for voice input
- Text-to-speech for voice output
## Usage
1. Click "Start Listening" to activate the voice assistant
2. Speak one of the available commands
3. The assistant will process your request and respond
4. Click "Stop" to deactivate the assistant
5. Use "Clear Chat" to reset the conversation history
## Project Structure
- main.py - The entry point of the application
- web/ - Contains all frontend files
  - index.html - The main HTML file
  - styles.css - CSS styling
  - app.js - JavaScript functionality
- assistant/ - Contains backend logic
  - Speech recognition modules
  - Command processing
  - API integrations
