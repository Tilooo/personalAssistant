Voice Assistant

Ready

Available Commands

  • Hello/Hi - Greet the assistant
  • What time is it? - Get the current time
  • Weather in [city] - Get current weather
  • News - Get latest news headlines
  • Sports news - Get sports headlines
  • Tell me a fact - Hear a random fact
  • Search for [topic] - Search the web
  • Tell me a joke - Hear a random joke
  • Add [task] to my to-do list - Add a task
  • Read my to-do list - Hear your tasks
  • Exit/Goodbye - Stop the assistant
